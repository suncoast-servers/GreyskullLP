# Greyskull UI icons

Line icons extracted from the approved UI prototype
(`deepseek_html_20261113_1a1429.html`), plus `repeat.svg`, `ladder.svg` and
`lock.svg` drawn in the same 24 px / 1.8 px stroke style for app-only methods.

Rendered with `flutter_svg` through `GsIcon`. Colours are applied at runtime
from the active skin, so the assets keep `stroke="currentColor"`.
