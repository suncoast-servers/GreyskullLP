# Contributing to GreyskullLP

GreyskullLP follows the **Suncoast Servers** pull-request workflow. Read the org guide first, then this repo’s onboarding doc.

| Resource | Purpose |
|----------|---------|
| [Org CONTRIBUTING.md](https://github.com/suncoast-servers/.github/blob/main/CONTRIBUTING.md) | PR-first git workflow, security expectations, AI tool guidance |
| [docs/COLLABORATOR.md](docs/COLLABORATOR.md) | Clone URL, branch naming, Flutter checks, communication |
| [AGENTS.md](AGENTS.md) | Rules for AI coding assistants (Cursor, Codex, etc.) |
| [docs/ROADMAP.md](docs/ROADMAP.md) | Release goals and prioritized backlog |

**Merge authority:** [@TheDevWhoSaysNi](https://github.com/TheDevWhoSaysNi) — contractors open PRs; Ryan (or explicit delegate) merges after review.

**Never push directly to `main`.** The `main` branch is protected (required PR + approval + CODEOWNERS review).
